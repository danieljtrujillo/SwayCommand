# Sway user manual, pages 30 and 31

Screen captures of two pages of Audima Labs' Sway user manual (`8.3 Sway
usermanual-7`, 37 pages). They are the source for the physical layout recorded
in [SWAY_INTEGRATION.md](../../SWAY_INTEGRATION.md) and were kept so a claim
about the hardware can be traced to the page it came from.

| File | Page | Content |
|---|---|---|
| `p30.png` | 30 | Hardware Overview, Figure 14: the unit with Drum Pads, Mappable Buttons, Display Screen and Scroll-click Wheel labelled |
| `p30b.png` | 30 | The same page at a larger zoom, with the figure caption and the page footer legible |
| `p30c.png` | 30 | The widest capture of the same page |
| `p31.png` | 31 | Component and Description table, the Drum Pads grid, the Grid Modes table |
| `p31b.png` | 31 | Byte-identical to `p31.png`; a duplicate capture, kept rather than removed |
| `p31c.png` | 31 | The component table alone |
| `p31d.png` | 31 | The pad grid and grid-mode tables alone |

The manual states the Reactive LED Beam as 16 RGB LEDs responding to hand
movement, customisable per region, which is the figure the sixteen-sensor count
throughout this project rests on.
